# Client

## New Features

- Users can now select a specific residential unit when registering a payment.
- The system automatically associates the correct residential unit with the payment when an invoice is selected.

## Improvements

- Duplicate interval records are now prevented to ensure data accuracy.
- Prevent any update on used intervals.
- Added safeguards to avoid invalid intervals, such as zero-value months, weeks, or years.

# Technical

## New Features

- New optional field was added in to payment model and its form view to specify residential unit.
- Automatic residential unit selection on register payment wizard.
- Common residential unit restrictions was created on `res.partner` model to handle `onChange` & constraints of dynamic residential unit selection for other models.

## Improvements

- Enable normal system users to access document tags , categories and history menus on document module.
- New interval constraints were created to prevent creating intervals with invalid values (e.g., zero months, weeks, or years).
- Prevented updates to interval records that are already in use.
- Hide `setup category wizard` menu from documents module menus
